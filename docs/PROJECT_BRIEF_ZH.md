# MoonShield 项目说明

**MoonBit Script Permission Policy Auditor & Runtime Conformance Tester**

## 解决的问题

开发者需要在运行脚本前发现过宽或歧义授权，还要识别命令行覆盖与运行时变化。只搜索文本或只看脚本头，可能误判转义值与生效策略。

## 实现与价值

- 官方 AST 保留重复字段与位置，字符串语义对齐固定 Moonrun 实现。
- MoonBit 实现规则、策略来源模型、CLI、报告和受控验证；EXE 仅为参数保真启动器。
- 中文/英文人工报告以及 JSON、SARIF；风险状态不因退出阈值放宽而消失，环境字面值隐藏。
- 真实 Moonrun 合成探针逐次保留命令与原始结果，不把权限拒绝、编译失败和配置错误混为一类。

## 现场可验收

风险定位与建议、转义星号识别、策略覆盖、SARIF 导出、候选正文未执行和真实运行验证。准确测试数量及失败修正以当前交付报告为准，不使用虚构 CI 徽章或演示数据。

## 原创与复用

原创部分包括审计模型、规则、语义适配、CLI/报告和证据测试。官方 parser/lexer、core 及 runtime 移植来源见 THIRD_PARTY_NOTICES.md。语言占比排除 vendor、生成文件和参考源码。

## 许可与状态

自有代码 Apache-2.0，第三方声明保留。当前源码按用户授权上传至 MoonShield 公开仓库，不补造历史。远程 CI 以 Actions 实际记录为准；报名和参赛身份未代用户执行。赛事截图仅作参考，资格及截止须核实官方章程。

## 边界

不执行候选正文、不证明脚本安全；不是容器或原生子进程沙箱。TOML、旧 YAML 和自动会话继承发现等明确未支持。锁不匹配或关键行为不稳定时停止放行。

## v1.2 优化

区分配置错误、覆盖不足与风险；保留原始授权及上下文提示。显式路径观察只读元数据，目录、别名和缺失路径继续复核。加入六份固定官方脚本的静态验收与虚构订单 CSV 的真实 Wasm 对照。Windows 同机干净目录与最小环境已纳入测试，不宣称完成其他电脑或系统测试。
